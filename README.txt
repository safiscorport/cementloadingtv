INSTALLATION
1. Back up your current dashboard folder.
2. Extract this ZIP.
3. Replace the four matching files in your dashboard folder.
4. Keep logo.png in the same folder (if your dashboard uses it).
5. Refresh the dashboard on the Smart TV / browser.

DISPLAY ADJUSTMENT
The Full HD Smart TV CSS now reserves a 10 mm (1 cm) clear strip at the bottom of the screen. The dashboard height is reduced by the same amount so the footer and lower panels fit within the remaining display area.

DATA NOTE
This package preserves the supplied data.json. Missing rows such as R3 or Berth F cannot be generated from this JSON if they are absent from the source workbook/data export.
